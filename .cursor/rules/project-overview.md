# Objetivo
Mejorar el layout de mi portfolio sin cambiar la lógica ni el contenido.

# Reglas de layout
- Mantener la estructura semántica: `<sidebar>`, `<main>`, `<section>`
- Mejorar alineación, espaciados y jerarquía visual
- No eliminar secciones existentes (sobre mí, proyectos, contacto)
- No eliminar subsecciones existentes en sección sobre mí como tecnologías, formación, experiencia y softskills
- Puedes reorganizar secciones para mejorar la lectura, pero sin borrar contenido
- Usar clases de Bootstrap existentes cuando sea posible
- No añadir librerías nuevas de estilos

# Reglas de comportamiento de la IA
- Antes de cambiar un archivo, explicar brevemente qué va a hacer y proponer una tarea
- No crear componentes nuevos si no son necesarios
- No tocar lógica de estado ni hooks, solo JSX y clases de estilo
- Si algo no está claro, preguntar en vez de inventar
